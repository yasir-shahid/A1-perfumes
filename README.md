# 🌿 A-ONE Luxury Fragrance

> **Experience Timeless Elegance in Every Drop**

A premium luxury fragrance website built using **React**, **Vite**, and **TypeScript**, designed for **A-ONE Luxury Fragrance**, a traditional Indian attar and premium perfume brand based in Nalgonda, Telangana.

The website offers an elegant and immersive experience, allowing customers to explore handcrafted attars, discover curated fragrance collections, learn about traditional perfumery, and connect directly with fragrance consultants.

## 🚀 Getting Started

Clone the repository

```bash
[git clone https://github.com/yasir-shahid/A1-perfumes.git]
```

Move into the project

```bash
cd A1-perfumes
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
